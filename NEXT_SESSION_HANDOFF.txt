Mobile Demo Lessons From 2026-05-23
-----------------------------------
- The phone could load Expo only reliably through Expo tunnel mode.
- Expo LAN mode can spin forever from WSL2 because the QR points at `192.168.0.105:8081`, and the phone may not reach the WSL2 Metro server through Windows networking/firewall.
- The FastAPI backend inside Docker worked locally at `http://localhost:8000/docs`, but the phone could not reach `http://192.168.0.105:8000`.
- The working pattern was:
  1. Start Docker backend.
  2. Start `localtunnel` for backend port 8000.
  3. Start Expo with `EXPO_PUBLIC_TELEDERM_API_URL=<localtunnel-url>` and `--tunnel --clear`.
- Do not type `https://https://...`; that caused Android to fail with `UnknownHostException` for host `"https"`.
- `localtunnel` URLs change between sessions. Always copy the fresh URL.
- Keep the `localtunnel` terminal open while using the phone app.
- The `SafeAreaView has been deprecated` warning is harmless for the demo.
- Old React Native FormData object upload failed with `Unsupported FormDataPart implementation`.
- Reading the picked image with `fetch(image.uri)` failed with `Could not read the selected image`.
- Current mobile upload uses `expo-file-system/legacy` multipart upload instead.

Next Mobile Run
---------------
Use `Run_mobile_app.md` first. Short version:

Terminal 1, repo root:

```bash
docker compose up -d api postgres
npx --yes localtunnel --port 8000
```

Terminal 2, mobile app:

```bash
cd apps/mobile
npm install
EXPO_PUBLIC_TELEDERM_API_URL=<fresh-localtunnel-url> npx expo start --tunnel --clear
```

Then fully close Expo Go on the phone, reopen it, scan the fresh QR, and login:

```text
patient@example.com
patient123
```
